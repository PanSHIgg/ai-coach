```bash
grep -ro "http://localhost:[0-9]*" miniapp/dist/build/h5/assets   # → index-DyTaOdnG.js: http://localhost:9000
# 源码依据：miniapp/src/api/request.ts:15（默认 'http://localhost:9000'）+ miniapp/.env.development:8
# 生产构建无 .env.production → VITE_API_BASE 未注入 → 内联回退到 localhost:9000

```

因 `:9000` 不可用且 Chrome 默认对回环地址绕过代理（尝试 `--proxy` / `--proxy-bypass "<-loopback>"` 均被回环放行），

```bash

agent-browser --session h5 set viewport 375 812
agent-browser --session h5 open "http://127.0.0.1:5177/#/pages/index/index"
# 校验 shim 生效：eval fetch('http://localhost:9000/api/auth/login',{code:'mock-code'}) → {"code":0,...}
```

> shim 仅存在于 `/tmp`，**未修改 `miniapp/` 源码或 `dist/` 产物**；真实后端对任意 code 走 mock 登录并真实建用户/发 JWT。
