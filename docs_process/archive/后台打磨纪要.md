## 1. 逐页修改

统一模式（列表类页面）：接口失败时区分两类——
- **无响应网络错误**（后端未启动）→ 保留既有「演示数据 + 黄条提示」降级，避免白屏；
- **其它错误**（403 无权限 / 5xx / 业务错误）→ 不再伪装成演示数据，改为**红色告警条 + 「重试」按钮**，数据区清空。

## 2. 一致性核对

- 导航 / 头部标题：沿用 `AdminLayout.vue` 的 `route.meta.title` 与菜单 `roles`，路由 `roles` 与之逐条对齐。
- 空态：`el-table` 在 `main.ts` 已装 `zh-cn` locale，空列表自动显示「暂无数据」，无需额外配置。
- 加载态：列表页 `v-loading` 原已存在；本次补齐看板卡片区与目录下拉的 loading。
- 危险操作二次确认：商家审核通过/驳回、内容审核通过/驳回原已有确认；本次补齐**券发放**的确认。

## 3. 遗留问题（定级）

- **P1** `admin/src/api/client.ts:39-53` 响应错误仅对 401 跳登录；**403 未单独提示「无权限」**，仅弹出后端 message。当前页面层已能把 403 渲染成错误+重试态，但文案依赖后端。`client.ts` 属禁碰文件，本次未改。建议后续由主 Agent 在拦截器区分 403 文案。
- **P2** 列表分页 `@change="load"` 在页大小变化时由 Element Plus 自行校正页码；若后端在筛选下 `total` 变小导致当前页越界，页面只显示空表（不自动回退），属可接受行为。
- **P2** `getDashboard(date?)` 支持日期参数，但看板页未提供日期选择器，恒取当日。属功能缺口非缺陷。
- **P2** `docs/` 未记录 admin 的独立部署（`deploy/docker-compose.yml` 中 admin 静态挂载仍被注释）——不在本任务白名单内，转由 deploy 子 Agent 处理。
- **已闭环（Phase 5 收尾）** **F7-P2a「后台 375 窄屏」**：侧栏固定 220px 不折叠导致内容被压缩、卡片文字截断。已在 `AdminLayout.vue`（`<992px` 折叠为图标栏 + 折叠按钮、表格横向滚动）与 `DashboardView.vue`（KPI `:xs=24` 堆叠）修复；**375/1440/1920 三档真后端复验通过、控制台零错误**（详见 `docs_process/兼容性测试报告.md` §6）。
