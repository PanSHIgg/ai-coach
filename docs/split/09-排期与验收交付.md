# 第十一部分：项目排期与里程碑

## 11.1 阶段总览

| 阶段    | 主要交付                |
| ----- | ------------------- |
| 准备    | 环境、仓库、UI 规范、数据库初始化  |
| M1 基础 | 登录、建档、热量账户、饮食/运动记录  |
| M2 AI | 拍照识别、AI 对话、饭点决策     |
| M3 商家 | 商家/SKU/券/订单/核销、管理后台 |
| M4 社交 | 五种社交、社区、动态          |
| M5 收尾 | 支付联调、测试、部署、上线       |

## 11.2 周任务明细

| 周   | 任务                      | 交付物                 |
| --- | ----------------------- | ------------------- |
| W1  | 建仓、Docker、UI 规范文档、建表、CI | 可跑的开发环境、建表脚本、设计令牌文件 |
| W2  | 微信登录、JWT、建档、首页热量账户      | 可登录建档、首页环形图可用       |
| W3  | 食物库导入、拍照识别、饮食 CRUD、步数同步 | 拍照即记录、账户实时更新        |
| W4  | TDEE/步数校准、体重趋势、提醒订阅     | 热量计算完整、订阅消息可用       |
| W5  | AI 对话、RAG 知识库、次数限制      | AI 能答、超限提示邀请        |
| W6  | 饭点决策、AI 教练卡片、异常处理       | 吃什么页可用              |
| W7  | 商家/目录/SKU/价格区间、LBS、券池   | 商家后台可上品定价           |
| W8  | 订单、支付、核销、平台管理后台         | 完整交易闭环              |
| W9  | 动态、监督、兴趣社群、挑战赛          | 社区基础可用              |
| W10 | 约战、榜单、AI 点评、内容审核        | 五种社交完整              |
| W11 | 支付联调、性能安全测试、文档补齐        | 测试报告、可上线包           |
| W12 | 部署生产、灰度、复盘              | 上线、监控告警生效           |

## 11.3 里程碑验收

- M1：可建档、可记录饮食运动、首页账户数字准确（对照手算表）。
- M2：AI 能回答 10 类常见问题，识别测试集准确率 ≥ 85%。
- M3：下单→支付→核销全链路跑通，券不重复核销。
- M4：五种社交均可用，内容安全拦截生效。
- M5：通过 Go-No-Go，生产环境稳定运行 7 天无 P0。

# 第十二部分：验收与交付清单

## 12.1 功能验收项

- [ ] 微信登录 + 建档 + 热量账户首页（含环形图、摄入/运动明细）
- [ ] 拍照记录（识别、确认、修正、写入、重算账户）
- [ ] 饮食/运动记录 CRUD、步数同步、TDEE 计算与步数校准
- [ ] AI 对话（含次数限制、邀请扩容提示）、饭点决策推荐
- [ ] 吃什么页（菜单识别、标准餐、商家比价、专家问诊）
- [ ] 运动页（标准项目、场馆比价、周期管理、硬件同步）
- [ ] 社区五种社交（监督、兴趣社群、约战、挑战赛、动态）
- [ ] 商家后台（选品、定价区间校验、选券、上下架、核销、数据）
- [ ] 平台管理后台（目录、商家、券、订单、内容、数据看板）
- [ ] 邀请裂变（海报、有效判定、权益发放、进度展示）
- [ ] 订单交易（创建、支付、券抵扣、核销、退款入口）
- [ ] 异常状态（加载/空/错误/无权限/未开通权益）全部覆盖
- [ ] 埋点上报 6 项核心指标

## 12.2 非功能验收

- [ ] 性能达标（9.4）
- [ ] 安全测试无高危、越权用例全通过
- [ ] 兼容性通过（9.3）
- [ ] 文档完整（代码 README、API 文档、部署手册、测试报告）

## 12.3 交付物清单

1. 微信小程序可运行包（已上传微信平台，体验版/正式版链接）
2. 后端源码 + Dockerfile + docker-compose.yml
3. 管理后台 H5 + 部署包
4. 数据库建表 SQL + 初始化数据脚本（食物库、标准目录）
5. 测试报告（功能/性能/安全）
6. 部署文档 + 监控看板截图
7. 埋点文档 + 首月数据报表
8. 本套开发交付文档
