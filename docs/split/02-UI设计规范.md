# 02 · UI/UX 设计规范

> 拆分自《AI 饮食管控教练 · 全栈开发交付文档》第四部分，内容为原文。

> 全栈开发同时负责 UI，本节是还原页面的唯一依据。所有数值可直接写进 CSS/小程序 wxss。

## 4.1 设计令牌（Design Tokens）

| 令牌             | 值                            | 用途               |
| -------------- | ---------------------------- | ---------------- |
| `--brand`      | #22C55E（鲜绿）                  | 主色：热量账户进度、主按钮、品牌 |
| `--brand-dark` | #16A34A                      | 主色按压/深底          |
| `--warn`       | #F59E0B（琥珀）                  | 警告：接近预算          |
| `--danger`     | #EF4444（红）                   | 超标、删除、券过期        |
| `--info`       | #3B82F6（蓝）                   | 运动、信息            |
| `--success`    | #10B981（绿）                   | 达标、成功            |
| `--bg`         | #F5F6F8                      | 页面背景             |
| `--card`       | #FFFFFF                      | 卡片底色             |
| `--text-1`     | #1F2937                      | 主文字              |
| `--text-2`     | #6B7280                      | 次要文字             |
| `--text-3`     | #9CA3AF                      | 占位/辅助            |
| `--border`     | #E5E7EB                      | 分割线              |
| `--radius-sm`  | 8rpx                         | 标签、小按钮           |
| `--radius`     | 16rpx                        | 卡片默认             |
| `--radius-lg`  | 24rpx                        | 弹窗、大卡            |
| `--shadow`     | 0 4rpx 16rpx rgba(0,0,0,.06) | 卡片投影             |
| `--shadow-lg`  | 0 8rpx 32rpx rgba(0,0,0,.12) | 弹窗投影             |

## 4.2 字体与字号

主字体 PingFang SC / 系统默认；数字用 DIN Alternate（如无可降级）。单位用 rpx。

| 令牌           | 字号    | 字重  | 用途          |
| ------------ | ----- | --- | ----------- |
| `--t-32`     | 32rpx | 500 | 大标题（页面标题）   |
| `--t-28`     | 28rpx | 500 | 模块标题、卡标题    |
| `--t-26`     | 26rpx | 400 | 正文          |
| `--t-24`     | 24rpx | 400 | 次要正文、按钮     |
| `--t-22`     | 22rpx | 400 | 辅助说明、标签内文   |
| `--t-num-lg` | 56rpx | 700 | 环形图中心数字     |
| `--t-num-md` | 40rpx | 700 | 大数值（已摄入/消耗） |

行高 1.5，字间距 0；标题字重 500，数值字重 700。

## 4.3 间距

4 点基准：xs=8rpx、sm=16rpx、md=24rpx、lg=32rpx、xl=48rpx。页面左右内边距 md（24rpx），卡片内边距 lg（32rpx），卡片之间间距 md（24rpx）。

## 4.4 圆角与投影

按钮默认 `--radius`；标签 `--radius-sm`；弹窗/底部弹层 `--radius-lg` 且顶部两角。卡片投影 `--shadow`，弹窗 `--shadow-lg`。

## 4.5 图标

图标库：使用 uni-icons 或 iconfont，尺寸 40rpx（列表图标）、48rpx（Tab）、64rpx（空状态插画）。配色跟随 `--text-2`，强调图标用 `--brand`。【假设】所有图标使用线性风格、2px 描边。

## 4.6 按钮

| 类型   | 样式                                              | 用途               |
| ---- | ----------------------------------------------- | ---------------- |
| 主按钮  | 底 `--brand`、字白、圆角 `--radius`、高 88rpx、字 `--t-28` | 核心操作（保存、立即支付、确认） |
| 次按钮  | 底白、边 `--border`、字 `--brand`                     | 次要（取消、稍后）        |
| 文字按钮 | 无底、字 `--brand`                                  | 内联操作（查看全部、换一个）   |
| 禁用   | 底 `#D1D5DB`、字白、不可点                              | —                |

按钮按压态：`opacity .85` 或加深底色。全宽按钮左右间距 md。

## 4.7 表单

标签在上、输入框在下；输入框高 88rpx、底白、边 `--border`、圆角 `--radius`、聚焦时边变 `--brand`。占位文字 `--text-3`。选择器（性别、活动水平）用分段控件或 Picker，选中态 `--brand` 底+白字。

## 4.8 表格

小程序内不做复杂表格，改用"卡片列表"呈现（每行一张卡，左标题右数值，底部操作）。管理后台 H5 用标准表格：表头 `--brand-dark` 底白字、行高 64rpx、斑马纹 `#F9FAFB`、悬停 `#F3F4F6`。

## 4.9 弹窗与提示

- 确认弹窗：标题 + 正文 + 次按钮"取消" + 主按钮"确认"，居中，圆角 `--radius-lg`，遮罩 50% 黑。
- 底部弹层：从底部弹出，顶部两角圆角，右上角关闭 X。
- Toast：黑底白字，居中偏上，1.5 秒自动消失。
- 加载：`wx.showLoading` 或骨架屏（灰块闪烁）。

## 4.10 导航与标签栏

顶部导航：返回箭头 + 标题居中 + 右侧可选操作，底白、边 `--border`。底部 5 Tab：图标 48rpx + 文字 20rpx，未选中 `--text-3`，选中 `--brand`，上边距 8rpx。

## 4.11 卡片

白底、圆角 `--radius`、投影 `--shadow`、内边距 lg。卡内第一行标题（左）＋可选操作（右），正文与辅助文字分两到三行，数值右对齐加大字重。

## 4.12 健康评分环与状态色

首页评分环：描边 12rpx，底色 `#E5E7EB`，进度色按区间：<60 红、60-80 琥珀、>80 绿。进度动画 800ms ease-out。状态点：🔴需关注、🟡建议、🟢正常、🔵服务（会员/复查）、🟠券即将过期。

## 4.13 暗色模式

【假设】首期不做暗色模式，全部浅色。若系统为深色，页面仍为浅色背景（不跟随），避免热量账户数字与绿环在深色下对比不足。

## 4.14 动效

页面切换右滑返回；卡片进场 300ms fade-up；环形图动画；按钮按压；下拉刷新标准菊花。不做复杂 Lottie。
