# 08 · 部署与运维

> 拆分自《AI 饮食管控教练 · 全栈开发交付文档》第十部分，内容为原文。

## 10.1 环境

- 开发：本地 Docker Compose（PG + Redis + FastAPI + Nginx）。
- 测试：腾讯云轻量服务器（2C4G）+ 独立 PG/Redis 实例。
- 生产：腾讯云轻量服务器（4C8G）+ 云数据库 PostgreSQL + 云 Redis + COS + CDN。

## 10.2 目录结构

```
/app
  /backend   FastAPI 源码
  /miniapp   uni-app 小程序源码
  /admin     Vue3 管理后台
  /deploy    docker-compose.yml、Dockerfile、nginx.conf
  /docs      本文档
```

## 10.3 Docker

- `Dockerfile.backend`：python:3.12-slim + 多阶段构建，非 root 运行，暴露 8000。
- `Dockerfile.miniapp`：node:20 编译（`npm run build:h5`，产物 `miniapp/dist/build/h5`）→ nginx 托管静态 H5、暴露 80（小程序走 uni-app 编译命令，非 Docker；构建上下文为 monorepo 根目录，`docker build -f deploy/Dockerfile.miniapp .`）。
- `docker-compose.yml`：web(api)、db、redis、worker、nginx，卷持久化 `pgdata`、`redisdata`、`uploads`。

## 10.4 Nginx

- 80 强制跳 443；443 配 Let's Encrypt 证书（Certbot 自动续期）。
- `/api/` 反向代理到 FastAPI `127.0.0.1:8000`；`/admin/` 代理前端静态；`/uploads/` 代理媒体。
- 静态资源缓存 7 天，HTML 不缓存；限流 `limit_req_zone` 100r/s。

## 10.5 数据库迁移

Alembic：新增字段/表先写迁移脚本 → 测试库验证 → 生产执行前备份 → 执行 → 验证行数。

## 10.6 回滚

Git Tag 打版本；构建镜像带 `git short sha` 标签。回滚：`docker compose down && docker compose up -d --scale` 切回上一镜像，数据库迁移若不可逆需另备反向脚本（【假设】首期迁移只做可加字段、不删不改列，保证可回滚）。

## 10.7 监控与日志

- 监控：Prometheus 拉取 `/metrics`（接口 QPS、延迟、错误率、热量账户计算耗时、AI 调用成本）；Grafana 面板。
- 日志：JSON 格式，含 `request_id` 链路追踪；落盘 `/var/log/app/`，Cron 每日打包上传 COS，保留 30 天。
- 告警：服务不可用 5 分钟、错误率 > 5%、磁盘 > 80%、AI 日成本超预算时企业微信/邮件告警。
